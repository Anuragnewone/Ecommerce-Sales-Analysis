📊 E-commerce Sales Analysis using SQL & Power BI
📌 Project Overview
This project focuses on analyzing raw e-commerce sales data using SQL for data cleaning and analysis, followed by visualization in Power BI. The objective is to extract meaningful business insights related to customer behavior, product performance, and regional trends.

🛠 Tools Used
* SQL (Data Cleaning & Analysis)
* Power BI (Dashboard & Visualization)

📂 Dataset
The dataset contains real-world e-commerce transaction data including:
* Invoice Number
* Product Description
* Quantity
* Unit Price
* Customer ID
* Country
* Invoice Date
* Price
The dataset includes missing values, duplicates, and inconsistencies, which were handled using SQL.

🧹 Data Cleaning Process
* Removed missing values (CustomerID, Description)
* Removed duplicate records
* Filtered invalid data (negative quantity)
* Created a new column amount = Quantity × UnitPrice

📊 Key Metrics
* Total Revenue: ₹528,510.12
* Total Orders: 282,441
* Average Order Value: ₹407.48

📈 Key Insights
* The business generated a total revenue of ₹528,510.12 from 282,441 transactions, indicating strong overall sales performance and high customer engagement.
* The average order value stands at ₹407.48, suggesting moderate customer spending per transaction and opportunities to increase revenue through upselling strategies.
* The United Kingdom is the primary revenue contributor, significantly outperforming other regions, while Poland generates the lowest revenue, highlighting regional performance gaps.
* Certain products are purchased in significantly higher quantities, indicating strong customer demand and the need for efficient inventory management.

💡 Business Recommendations
* Focus marketing and operations on high-performing regions like the United Kingdom
* Improve performance in low-performing regions through targeted strategies
* Increase inventory for high-demand products
* Implement upselling and cross-selling strategies to increase average order value
